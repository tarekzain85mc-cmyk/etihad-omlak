# M0-005 — حفظ مظهر التطبيق

## الهدف

يبقى اختيار المظهر الفاتح أو الداكن أو عالي التباين بعد إغلاق تطبيق Android
وإعادة فتحه، سواء اختاره المستخدم من شاشة الدخول أو الصفحة الرئيسية.

## النطاق

- حفظ قيمة المظهر فقط في تفضيلات الجهاز المحلية؛ لا حسابات أو بيانات سكان.
- قراءة القيمة قبل إنشاء واجهة التطبيق لتجنب ظهور ثيم مختلف لحظة البدء.
- الرجوع إلى المظهر الفاتح إذا كانت القيمة غير معروفة أو تالفة.
- إظهار تنبيه إذا تعذر حفظ اختيار جديد، مع إبقاء الاختيار ظاهرًا في الجلسة الحالية.

## Skills used

- test-driven-development
- frontend-ui-engineering
- graphify
- documentation-and-adrs

## القبول

- الخيارات الثلاثة تبقى بعد إعادة التشغيل.
- التغيير من شاشة الدخول أو الصفحة الرئيسية يستخدم الإعداد نفسه.
- قيمة محلية تالفة لا تمنع فتح التطبيق.
- تنسيق Dart والتحليل والاختبارات وبناء APK Debug تنجح.

## أثر الأمان والبيانات

- المفتاح المحلي `etihad.theme_mode` يحفظ اسم الثيم فقط، بلا معرفات أو أسرار.
- لا تغيير في Auth أو RBAC أو RLS أو المالية أو مخطط قاعدة البيانات أو الدفع.
- لا حاجة إلى تعديل اختبارات عزل العمارات لهذه المهمة.

## التحقق والرجوع

- اختبار `theme_preferences_test.dart` فشل أولًا لأن التخزين لم يكن موجودًا،
  ثم نجح بعد التنفيذ.
- اختبار واجهة يعيد تشغيل نقطة دخول التطبيق ويتحقق من بقاء الداكن والتباين
  العالي، بما في ذلك تغيير الاختيار من كلتا الشاشتين.
- اختبارا فشل الحفظ وتغيير الثيم السريع فشلا أولًا، ثم نجحا بعد إضافة مفتاح
  `ScaffoldMessenger` وتسلسل عمليات الحفظ؛ يبقى الاختيار الأخير هو المحفوظ.
- `dart format --output=none --set-exit-if-changed .` و`flutter analyze --no-pub`
  نجحا، و`flutter test --no-test-assets --no-pub` نجح في 10 اختبارات.
- `flutter test` العادي تعثر محليًا في حذف `build/unit_test_assets` داخل OneDrive؛
  خيار `--no-test-assets` تجاوز القفل دون أن يغيّر اختبارات الواجهة. سيعيد CI
  تشغيل الأمر العادي على Linux.
- `flutter build apk --debug --no-pub` تعثر محليًا عند تنزيل AndroidX من
  `dl.google.com` بسبب TLS/DNS؛ [CI #42796812478](https://github.com/tarekzain85mc-cmyk/etihad-omlak/actions/runs/42796812478)
  نجح على `4fd5489`، بما في ذلك `flutter test` العادي وبناء APK Debug وفحص الأسرار.
- Graphify حدّث الرسم محليًا بنمط code-only: 179 عقدة و196 علاقة؛ المخرجات غير
  مرفوعة. مراجعة Strix الساكنة لم تجد أسرارًا أو بيانات سكان، وكشفت مشكلتي
  التنبيه وتسلسل الحفظ اللتين صُححتا مع اختبارات إعادة إنتاج.
- عند الحاجة يمكن الرجوع عن commit هذه المهمة؛ الإعداد المحلي القديم غير حساس
  وسيتجاهله التطبيق بعد الرجوع.
