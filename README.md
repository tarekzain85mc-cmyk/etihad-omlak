# اتحاد الملاك

تطبيق Android عربي لإدارة اتحاد ملاك العمارة بشفافية: الاشتراكات، المتأخرات، المصروفات، فواتير العمارة، الأخبار، الإشعارات والتصويت.

## الحالة

المشروع في مرحلة `M0 — Foundation`. الاسم التجاري مؤقت، واسم الحزمة المقترح `com.etihadomlak.app`.

## التقنية

- Flutter لتطبيق Android مع دعم RTL والثيمات.
- Supabase للمصادقة، Postgres، التخزين، الإشعارات الخادمية وسياسات RLS.
- Fawry Hosted Checkout في مرحلة دفع تجريبية فقط.
- InstaPay يبدأ كتحويل موثق بمرجع وإيصال؛ لا يوجد تكامل API غير موثق.

## قواعد أساسية

- كل عمارة مساحة مغلقة بالدعوات، ولا يوجد انضمام أو بحث عام.
- الدور مرتبط بعضوية المستخدم في عمارة محددة.
- الصلاحيات تُفرض في قاعدة البيانات، لا في الواجهة فقط.
- لا تُحذف القيود المالية المعتمدة؛ التصحيح بقيود عكسية وسجل تدقيق.
- لا أسرار أو مفاتيح دفع أو توقيع Android داخل Git.
