# Threat Model

## الأصول الحساسة

بيانات السكان، أرقام الهاتف والبريد، أرصدة الوحدات، الإيصالات، المصروفات، أصوات السكان، أسرار الدفع، وسجل التدقيق.

## التهديدات الرئيسية والضوابط

| التهديد | الضابط الإلزامي |
| --- | --- |
| قراءة بيانات عمارة أخرى | `building_id` + RLS + اختبارات مستخدمين من عمارتين |
| ترقية صلاحية ذاتية | منح الأدوار عبر Function خادمية وتدقيق Admin/President |
| كشف مديونية جار | سياسة وحدة/عضوية واختبارات سلبية لكل دور |
| تكرار رسوم أو callback | معاملات ذرية و`idempotency_key` فريد |
| حذف أو تزوير قيد مالي | لا حذف بعد الاعتماد؛ قيد عكسي + audit event |
| تزوير Webhook | توقيع، timestamp، nonce ومنع replay |
| تسريب الأسرار | خزنة CI/Server فقط وsecret scanning |
| الاستيلاء على الإدارة | MFA للإدارة/المالية وحماية آخر Admin |
| تصويت مزدوج | قيد فريد على poll + voter scope ومعاملة ذرية |
| رفع ملف خبيث | نوع وحجم مسموحان، فحص، Storage خاص وروابط مؤقتة |

## قواعد الاختبار

- Matrix تلقائية: كل دور × كل جدول × عمارة العضو/عمارة أخرى.
- اختبارات recovery للنسخ الاحتياطية قبل أي إصدار مالي.
- Strix مراجعة ساكنة داخل المستودع فقط؛ لا فحص نشط لأي خدمة أو بيانات حقيقية دون موافقة جديدة.
