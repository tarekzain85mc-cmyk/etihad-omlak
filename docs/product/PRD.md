# متطلبات المنتج — اتحاد الملاك

## الرؤية

منصة مغلقة لكل عمارة تتيح للسكان معرفة ما عليهم، وما دُفع، وأين صُرفت أموال الاتحاد، مع إدارة صلاحيات واضحة وإشعارات وتصويت موثوق.

## المستخدمون والأدوار

| الدور | النطاق الأساسي |
| --- | --- |
| Admin العمارة | إنشاء العمارة والدعوات والعضويات ومنح أو سحب كل الأدوار وإعدادات العمارة |
| رئيس الاتحاد | نفس سلطة Admin داخل العمارة مع التقارير والموافقات |
| المدير المالي | الاشتراكات والمدفوعات والمصروفات والفواتير والمطابقة والتقارير |
| مدير الأمن | البلاغات والتنبيهات الأمنية فقط، دون أرصدة السكان |
| المدير الفني | طلبات الصيانة وأوامر العمل والأصول والموردون |
| عضو المجلس | التقارير المعتمدة والتصويت والموافقات المفوضة |
| ساكن | مستحقات وحدته وسجل دفعها، المصروفات المنشورة، الأخبار، التصويت والطلبات |

الدور مرتبط بـ`building_id`. يمكن للحساب نفسه أن يكون رئيسًا في عمارة وساكنًا في أخرى.

## التسجيل والانضمام

- بريد وكلمة مرور، أو هاتف وOTP، أو ربط الاثنين بالحساب نفسه.
- حقل كلمة المرور يدعم الإظهار والإخفاء.
- استرجاع كلمة المرور بالبريد، وإعادة إرسال OTP للهاتف.
- لا يمكن إنشاء عضوية في عمارة من التطبيق العام. Admin أو رئيس الاتحاد ينشئ دعوة محددة المدة مرتبطة بوحدة ودور مبدئي.
- Admin لا ينشئ كلمة مرور للمستخدم ولا يطّلع عليها.
- يمنع النظام إزالة آخر Admin/رئيس فعال من العمارة قبل تعيين بديل.

## الصفحة الرئيسية

- خبر أو إعلان مثبت.
- إجمالي المطلوب من وحدة المستخدم وأقرب موعد استحقاق.
- آخر المدفوعات والمصروفات المعتمدة.
- فواتير العمارة القادمة أو المتأخرة.
- التصويتات المفتوحة والتنبيهات المهمة.
- وصول سريع لرفع إيصال أو إنشاء طلب صيانة.

## المالية

- دورات اشتراك شهرية أو ربع سنوية وقواعد احتساب حسب الوحدة.
- رسوم، مدفوعات، تخصيص دفعات، مصروفات، فواتير ومرفقات/إيصالات.
- تذكير قبل الاستحقاق وبعده مع مستويات تصعيد قابلة للضبط.
- الساكن يرى حساب وحدته فقط، ويرى المصروفات المنشورة للعمارة.
- القيد المعتمد لا يُحذف؛ التصحيح بقيد عكسي مع سبب ومراجع.
- إنشاء الرسوم واستقبال callbacks يستخدمان `idempotency_key` لمنع التكرار.

## الدفع

- Fawry Hosted Checkout أو تكامل رسمي في Sandbox أولًا، والتحقق من callback والتوقيع على الخادم.
- InstaPay: عرض IPA/الحساب ومرجع تحويل فريد، ثم رفع الإيصال واعتماد المدير المالي. لا يُستخدم API خاص أو غير موثق.
- حالات الدفع: `created → pending → paid | failed | expired | refunded`.

## الأخبار والتصويت

- أخبار عادية ومثبتة ومهمة، مع إشعار Push/In-app.
- تصويت بموعد فتح وإغلاق وخيارات وقواعد أهلية واضحة.
- يمنع التصويت المكرر، ويحدد قرار المنتج لاحقًا هل الصوت للفرد أم للوحدة.
- نتائج مرحلية أو نهائية حسب إعداد التصويت.

## المظهر وإمكانية الوصول

- العربية RTL أولًا مع قابلية إضافة الإنجليزية.
- ثيم Light وDark وHigh Contrast.
- تكبير النص، تباين مناسب وتسميات قارئ الشاشة للعناصر الحرجة.

## خارج MVP الأول

- نشر متجر الإنتاج، تحصيل InstaPay آلي غير موثق، إدارة مجمعات متعددة، محاسبة ضريبية كاملة، أو دخول عام للعمارات.

## مؤشرات القبول

- اختبارات عزل تمنع كل دور من قراءة عمارة أو وحدة أخرى.
- تطابق إجمالي الرسوم والمدفوعات والتخصيصات دون فروق.
- Audit log لكل تغيير حساس.
- لا توجد أسرار في APK أو المستودع.
